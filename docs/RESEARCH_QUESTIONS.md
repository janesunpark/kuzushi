# Research Questions

This document tracks the research questions that will guide the Gold aggregation layer and downstream exploratory analyses in Kuzushi.

Rather than creating aggregated datasets arbitrarily, each Gold table will be designed to support one or more specific research questions about cognitive growth, academic learning, and embodied skill development. As the project evolves, this document will record the motivation, planned analytical approach, and expected output for each question, helping ensure that the data pipeline remains aligned with the project's long-term research objectives.

This file is currently a planning document and will be expanded as the Bronze, Silver, and Gold pipeline layers are completed.
